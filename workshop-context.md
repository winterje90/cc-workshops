# Workshop Series Overview (3 x 90 minutes)

**Order:** Jacob → Joe → Eric

1. **Context OS Starter Kit (Jacob)**
   Build a simple, file-based "company brain" from working docs and call transcripts so you can reuse context and reduce repeated explainers.

2. **Reusable GTM Skills in Claude Code (Joe)**
   Create a couple reusable "skills" that turn any website into structured notes + usable GTM outputs, then reuse across your site and competitors.

3. **ICP → TAM Lists + Enrichment + Channel Strategy (Eric)**
   Use customer data to find ICP patterns, generate a high-quality list (not necessarily the whole TAM), and apply a practical LinkedIn vs email playbook.

---

## Cross-Speaker Synthesis (How the Series Connects)

- **Compounding is the through-line.**
  Jacob's "context packages" persist changes and become a compounding asset over time.
  Joe frames Claude Code's power as the compounding effect of reusable skills.

- **File-based workflows reduce mystery and help adoption.**
  Jacob emphasizes removing the "terminal is scary" mystery by grounding it in file system basics.
  Joe makes it concrete with "build a function-like skill, then run it on multiple domains."

- **Start small, make it click, then scale.**
  Jacob recommends small live batches so people get the concept quickly.
  Eric aims for a "rock solid list" over "entire TAM," then scale from there.

- **Systems need ownership.**
  Jacob calls out the need for an arbiter / "benevolent dictator" to keep the system useful.
