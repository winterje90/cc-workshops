# Workshop 2 (Joe): Build Reusable GTM Skills (Website → Brief → Copy) in Claude Code

## Who it's for
GTM leads, product marketing, founders, and operators who want repeatable Claude Code workflows.

## Learning goals
By the end, participants can:
- Create a reusable skill that generates good content from scraped website data.
- Create a second reusable skill that synthesizes scraped info into a company overview.
- Run the same skills on their own site and competitors to see the "function you can rerun" effect.
- Keep homework light: install Claude Code, then follow along.

## Pre-work
- Install Claude Code (that's the only required homework).

## 90-minute agenda

**0–10 min — Why skills matter**
- The "compounding effect": build once, reuse many times.

**10–20 min — Pick universal inputs**
- Competitors and web research are universal GTM tasks.

**20–40 min — Live build: Skill #1 (Website → structured content)**
- Build a skill abstracted from any single company.
- Output: structured notes/content derived from a website.

**40–55 min — Hands-on: run Skill #1 on your own site**
- Everyone runs it on their domain.
- Quick "what looks wrong / what's missing" share-out.

**55–70 min — Live build: Skill #2 (Scrape → company overview)**
- A second skill to synthesize into a company overview.

**70–82 min — Hands-on: reuse on competitors**
- Run both skills on your main competitor and a third domain.
- Save outputs and compare differences.

**82–90 min — Wrap and reuse plan**
- Save the skills so you can run them again later (the "light bulb moment").

## Hands-on activities
- Build two skills (website → content; website → overview).
- Run them on: your company + competitor + third domain.

## Key takeaways
- Skills should be abstract so they're reusable across domains.
- Reuse is where the payoff is.

## Optional Enhancements
- Add a simple output rubric (clarity, differentiation, proof, ICP specificity).
- Add a brand-voice file and force outputs to match it.
- Add a peer review step: run → critique → iterate.
